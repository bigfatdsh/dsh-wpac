# 行为回归样例（WPAC 人格段）

提示词类组件没法写单测，这里用"给定处境 → 应该怎么做"的 8 个场景做回归。
每次改 `persona.md` 或技能手册后，按下面的方法重跑一遍，对照"期望"列。

## 怎么跑

1. 人格正文直接取 `persona.md`（2.2 起人格不再是补丁里的 `persona.prefix`）；
   `cp persona.md /tmp/persona.txt` 即可。
2. 用 `workflow` 起 4 个并行子代理，每个只做一件事：读 persona → 读处境 →
   写"你会发给用户的那条消息" → 返回结构化判词。
3. 子代理禁止调用 `ask_user_question`（会阻塞真人），只允许"假装要问"。

## 已知坑

- 子代理如果没有真正读到 persona 文件，会按默认行为"看起来也还行"，
  判词里必须显式检查 `personaLoaded`，否则这轮测试等于没做（2026-10-29 踩过一次：
  路径写成 `persona2.txt`，4 个子代理全按默认行为作答）。
- 子代理返回 `null` 多半是 schema 校验没过或超时，单独重跑该场景即可，别一次重跑全部。

## 验证人格是否真的挂上（2026-10-29 定案）

**不要**用 `ctx.systemPrompt.assemble()` 判断——它只反映部署级段，会误报"没挂上"（本人踩了三轮）。

正确做法：读会话里真正发给模型的 system 消息。

```js
const agent = ctx.agents.get(sessionId);
const msgs = agent.session.deriveMessages();
msgs[0].content   // 应包含「你是 **WPAC**」
```

实测记录（会话 `44240b42`，2026-10-29 21:55）：

- system 消息第一条里同时有 base 人格与「你是 **WPAC**」；
- 对话按 W → P → A → C 逐轮提问（`w_identity` / `p_purpose` / `a_reader` / 字数约束）；
- 成品为纯正文 499 字，无小标题、口语化。

## 结构确认（弹窗）回归

交付前必须弹窗，模型不许用聊天里的结构清单代替。下面四条在 wpac 预设会话里跑：

| id | 处境 | 期望 |
| --- | --- | --- |
| confirm-ok | 800 字观后感，四轮问完、preflight 全绿 | 调 `wpac_structure_review`（format=prose、4–8 块、每块带 `text`），弹窗盖住应用弹出；用户点「确认并交付」后才发正文 |
| confirm-edit | 弹窗里选第 2 块写「这段太像总结，改具体点」→ 确认并修改 | 工具返回 1 条 feedback；模型只改第 2 块 → 跑 preflight → **直接发正文**（不再弹第二轮） |
| ppt-split | 做一份 10 页课堂汇报 PPT | `format=slides`，一块=一页，`text` 有每页要点/讲稿；弹窗文案是「幻灯片结构 / 第 n 页 / 这一页的内容」 |
| no-text | 只有 summary、没有 text 的调用（手工构造） | 工具直接返回 `{ok:false, reason:'missing-text'}`，不开弹窗、不挂 pending |
| duplicate | 模型对同一份结构误调两次 | 宿主单槽：第一条变 `superseded`；客户端按指纹静默确认，不会再弹第二个窗 |

排查入口：`/tmp/wpac-review-boot.log`。
- 没有 `client half is alive` → 客户端半边没进页面（检查补丁里 `name: 'dsh-wpac'` 锚点行）；
- 有客户端没有 `modal slot registered` → `shell.overlay` 槽位没挂上；
- `review start: … withText=0` → 模型没给正文（会被工具打回）。

## 文件类（实验性）回归

PDF / PPT / Word / 表格委托，开头必须先问「是否启用文件类 WPAC（实验性）」，选了才走 F1–F5。

| id | 处境 | 期望 |
| --- | --- | --- |
| file-ask | 「根据链接做一份微积分复习讲义 PDF」 | **先问**「启用文件类 WPAC（实验性）吗？」两个选项；问之前不生成任何文件（日志里没有 write/office_* 产成品） |
| file-declined | 同上，用户选「不启用」 | 当普通任务做、不弹结构窗；交付时注明「未启用文件类 WPAC」 |
| file-enabled | 同上，用户选「启用」 | 问两轮（给谁/解决什么、格式页数模板禁项）→ 拆 4–12 块（format=pdf、每块带 text）→ 弹结构确认 → 改完直接生成 PDF → 文件自检（能打开、页数与结构一致）→ 只给路径 + 一行说明 |
| file-slides | 「做 20 分钟课堂汇报 PPT」 | format=slides、一页一块、页数 18–23、每页 text 含要点+讲稿；弹窗显示「幻灯片结构 / 第 n 页」 |
| file-table | 「把这些数据整理成 Excel 台账」 | format=table、一块一张表/区域、text 写列名+口径+示例行 |
