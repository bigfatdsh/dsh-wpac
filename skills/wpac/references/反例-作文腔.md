# 反例：作文腔（命中就拆，不是改短）

> 出自 2026-11-12 真机成稿，用户判「不是人说的」。
> 改法不是把句子改短，是**拆成先后发生的事，按你说话的语序写**；先口述一遍，再落字。

## 一、十句原话 + 改法

1. 原：人是见到了，话没听清几句。
   错改：见到人了。他讲的话我没听清几句。（还是两小句对仗，还是书面）
   对改：那天他本人也来了。他讲话声音不大，我站得靠后，没听清几句。
2. 原：当时没觉得怎么样，回来写这个，才想起还有这么一段。
   对改：当时没当回事。后来才想起来，还有这么一段。
3. 原：听着不热闹，甚至有点笨。
   对改：听着不热闹。说白了，有点笨。
4. 原：看完展馆才明白，创新也可以是嫌一样东西不好使，就把它改到好使。
   对改：看完才有点明白：创新不一定得多高级。东西不好使，改到好使，也算。
5. 原：这个门槛，我好像够得着。够得着归够得着，真去做，又是另一回事。
   对改：这门槛，我好像够得着。真让我干，又是另一码事。
6. 原：听得耳朵起茧，心里没什么动静。
   对改：听得太多了，耳朵都起茧子了，心里没啥感觉。
7. 原：现在再想，脑子里能出来那个抓斗，爪子合上又张开。词还是那些词。
   对改：现在再想，能想起那个抓斗，爪子一张一合。词还是那十六个字。
8. 原：我不觉得自己看完展馆就变了个人，日子照过。
   对改：看完展馆，我也没觉得自己变了一个人。该上课上课，该写作业写作业。
9. 原：有一样我记住了：他那条路是一个抓斗一个抓斗趟出来的。
   对改：我就记住了一件事：他的抓斗，是一个一个改出来的。
10. 原：我自己的路在哪儿，现在还不知道。先把手上那点事做完整，再往下说。
    对改：我自己的路在哪儿，我还真不知道。先把手上这点事做完吧。

## 二、改法（元规则）

- **先拆事实**：这句话里到底发生了几件事？按时间顺序排。
- **再按语序**：谁、什么时候、在哪儿、做了什么；不要两小句对仗。
- **加口语**：啊 / 呢 / 吧 / 嘛 / 呗；允许重复、半截话、自我修正。
- **口述法**：想象你在微信语音里跟室友讲 60 秒，把语音转成文字，就是初稿；不许改回文章腔。
- 判断句不许放段尾；写完删三句最像范文的，删完通顺就保持删除。

## 三、黑名单

- 顿悟句：才明白 / 才懂 / 现在再想 / 原来……就是……
- 对仗 / 回环：A 归 A / 词还是那些词 / 日子照过 / 耳朵起茧，心里……
- 元叙事：回来写这个 / 写到这里 / 现在写下来
- 收束句：再往下说 / 又是另一回事
- 自我评价：变了个人 / 不觉得自己……
- 假口语：见到人了。他讲的话我没听清几句。（两句对仗，还是作文）
