# 反例：作文腔（命中就删 / 改）

> 这些句子出自 2026-11-12 的真机成稿，用户判「不是人说的」。写心得 / 观后感时一律不许出现；preflight 会拦。

1. 人是见到了，话没听清几句。
   → 见到人了。他讲的话我没听清几句。
2. 当时没觉得怎么样，回来写这个，才想起还有这么一段。
   → 当时没觉得什么，后来才想起来。（不许提「写这个」）
3. 听着不热闹，甚至有点笨。
   → 听着不热闹。（删后半句）
4. 看完展馆才明白，创新也可以是嫌一样东西不好使，就把它改到好使。
   → 看完才知道，创新也可以是把不好使的东西改到好使。
5. 这个门槛，我好像够得着。够得着归够得着，真去做，又是另一回事。
   → 这个门槛，我好像够得着。真去做，可能又是另一回事。
6. 听得耳朵起茧，心里没什么动静。
   → 听得多了，没什么感觉。
7. 现在再想，脑子里能出来那个抓斗，爪子合上又张开。词还是那些词。
   → 现在再想，能想起那个抓斗。
8. 我不觉得自己看完展馆就变了个人，日子照过。
   → 看完展馆，我也没觉得自己有什么变化。
9. 有一样我记住了：他那条路是一个抓斗一个抓斗趟出来的。
   → 我就记住了一件事：他的抓斗是一个一个改出来的。
10. 我自己的路在哪儿，现在还不知道。先把手上那点事做完整，再往下说。
    → 我自己的路在哪儿，还不知道。先把手上这点事做完。

## 句式黑名单

- 顿悟句：才明白 / 才懂 / 现在再想 / 原来……就是……
- 对仗 / 回环：A 归 A / 词还是那些词 / 日子照过 / 耳朵起茧，心里……
- 元叙事：回来写这个 / 写到这里 / 现在写下来
- 收束句：再往下说 / 又是另一回事
- 自我评价：变了个人 / 不觉得自己……

## 用法

写完逐条搜一遍；命中就删或改；改完再跑 preflight。
