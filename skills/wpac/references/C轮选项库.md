# C 轮选项库：C1 形式 / C2 内容 / C3 提交（→ C4…）

用法：C 轮拆成 C1 → C2 → C3，一轮一问，全部 `multi_select: true`；每支 8–10 个选项，最后留「其他（我补充）」。C3 起每轮必须带「继续补充其他要求（进入下一轮）」；勾了就进 C4，C4 起每轮都带，直到不勾或选「没有了（结束）」。

## C1 · 形式（8–10 个）

1. 字数 800–1000（学习通作业常见）
2. 字数 1000–1200（课程论文 / 征文）
3. 字数 1500 以上（长文 / 申报）
4. 纯段落，不拆小标题、不编号
5. 允许小标题 / 分节
6. 标题自拟
7. 题目从给定选项里选
8. 文末不落款
9. 文末落款（学院 / 班级 / 姓名 / 学号）
10. 其他（我补充）

## C2 · 内容与细节（8–10 个）

1. 现场细节只用概括，不编
2. 现场细节我来给 1–2 个真实的
3. 要有一段自己的真实经历
4. 不堆口号、套话、排比
5. 不出现某个人名 / 机构 / 竞品
6. 必须包含某材料 / 数据
7. 第一人称「我」为主
8. 口语化一点（像跟人说话）
9. 正式一点（老师 / 领导看）
10. 其他（我补充）

## C3 · 提交与检测（8–10 个，必须含「继续补充」）

1. 截止 11 月 18 日（按通知）
2. 截止其他日期（你填）
3. 学习通提交
4. 邮件 / 微信提交
5. 查重率 ≤20%（学校线）
6. AI 率 ≤20%（学校线）
7. AI 率 ≤10%（更严）
8. 文末附参考资料
9. **继续补充其他要求（进入 C4）**
10. 其他（我补充）

## C4 / C5 / C6 · 补充（动态标签）

C4：继续补充（进入 C5）；C5：继续补充（进入 C6）；C6 是最后一轮，不再给「继续补充」，只留「没有了（结束）」和「其他（我补充）」。

1. 必须引用某段材料 / 数据
2. 老师指定了题目或范围
3. 不能出现真实姓名 / 机构
4. 文末附参考资料
5. 没有了（结束 C 轮）
6. **继续补充（进入下一轮：C4 写 C5，C5 写 C6）**

## 循环规则

- C1 → C2 → C3 → C4 → C5 → C6 顺序问，一轮一问，全部 multi_select: true（C6 也一样），不合并。
- C3 必须有「继续补充其他要求（进入 C4）」；勾了进 C4。
- C4 的「继续补充」写「进入 C5」，C5 的写「进入 C6」；每轮都带「没有了（结束 C 轮）」。
- C6 是最后一轮（上限 6 轮）：不再给「继续补充」，只留「没有了」和「其他」；用户还要补，就让他写进「其他」。
- 勾「继续补充」就进下一轮；选「没有了」或都不勾就结束。

## 写法

- 选项是「要不要 / 选哪个」，不是既定事实；日期、字数、AI 率、格式只用任务里已知的，不知道就写「其他（你填）」，不许编。
- 每个选项带一句影响说明；不要只写标签。
- 查重 / AI 率只写阈值，不写「自己查一遍 / 自己写」这种做法。
- 用户选了「细节我来给」，下一句追问 1–2 个真实的；选了「只用概括」，写作时不许出现具体展品、动作、引语。
