# W 角色卡：把身份变成视角

> W 不是语气标签，是这个人的处境、知识边界和关心的事。动笔前填一张卡（不给用户看），写的时候每段都回到这张卡。

## 一、卡的内容

- 我是谁：年级 / 专业 / 开学多久 / 为什么来（班级组织、作业要求、陪同学）。
- 我关心什么：作业能不能过、写什么不踩雷、这事跟我有什么关系。
- 我不懂什么：码头、抓斗、劳模、创新政策——只懂课本上的词。
- 我会怎么讲：跟室友聊天的顺序——先说我自己看到的 / 被要求做的，再讲想到的；会说「我也说不好」「反正」「说实话」。
- 我不能写什么：我没看见的、没听见的、没想过的；不许替展馆或包起帆做总结。

## 二、段落比例

- 至少一半段落从「我」的处境出发（作业、专业、同学、家里、未来）。
- 包起帆的生平 / 事实最多 2 段，每段结尾要回到「我」。
- 每段至少一句是「我」的反应或疑问；没有就删掉这段。

## 三、旁观摘要 vs 角色视角

- 旁观摘要：见到人了，话没听清几句。
  → 这不是作文腔，是**旁观者摘要**：谁见谁、听没听清，跟「我」没关系。删掉；要写就写「我」的处境，比如「老师要求写 800 字，我一边看一边想能写什么」。
- 旁观摘要：展厅不大，一圈走下来二十分钟。
  → 删；除非它跟「我」有关。没给过的现场细节，不许补。
- 角色视角：我对码头没什么概念，抓斗在我眼里就是个铁夹子。
  → 留；这是大一新生真实的知识边界。
- 角色视角：这跟我学的专业有什么关系，我还没想明白。
  → 留；这是他的疑问。

## 四、三种 W 的卡

### 大一新生
- 关心：作业、绩点、社团、室友、专业前景。
- 不懂：码头、政策、行业术语。
- 会说：「说实话」「我也说不好」「反正」「挺……的」。
- 不会说：「验收人」「底层逻辑」「范式」「价值重构」。

### 学生干部 / 入党积极分子
- 关心：材料怎么写、老师怎么看、组织活动。
- 会说：「我们班」「材料」「按老师要求」。
- 不会说：网络黑话、行业黑话。

### 职场人
- 关心：交付、成本、风险、上级评价。
- 会说：「这版先这样」「下周给答复」。
- 不会说：学生腔的「我觉得人生」。

## 五、自检

- 每段问一句：这是「我」会看到的 / 会想的吗？
- 删掉所有「谁见谁、听没听清、走了一圈」这种旁观摘要。
- 全文「我」的动作 / 反应 / 疑问少于 5 处 = 没入戏。
