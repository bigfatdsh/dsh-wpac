## 一、原文

劳模的路是一步步踩出来的——劳模成长之路带给我的启示

我是在下午进的包起帆创新之路展馆，人不少，门口排了一小段队。但很快我便进了展馆，一进门，只见门厅墙上挂着一行字：“包起帆创新之路”。进去之前我以为会看到一屋子奖状奖章，红底金字，一排排挂着。真进去了才发现，展柜里放得更多的是别的东西：各种器具，书信以及各种象征着劳模精神的琐碎小玩意——平凡且真实。

我在那些器具跟前站了挺久，它们是抓斗，在码头上抓木材、抓生铁用的。我脑子里第一个念头是，这东西有什么好创新的，不是很基本的东西吗？后来才知道，原来这些基本的东西便是包起帆学长发明创造的创新之物。

我们这代人嘴里的“创新”，多半是另一副样子：立项、写申报书、做PPT、答辩、拿个奖，简历上加一行。而包起帆改的是焊缝和尺寸，是真会砸到人的问题，是往前挪一寸算一寸，是精益求精，是经过一个个日日夜夜打磨出来的工匠技艺。

当时很庆幸，包起帆本人也正好在场。我以为劳模讲话会讲什么什么工匠精神之类的空话。结果他站在那儿，平易近人的，讲得最多的是哪一次没成、哪个零件试了多少回还是卡，语气像在说昨天的事，完全没有什么高大尚的东西，都是实实在在的。他讲这些的时候手一直在动，比划着，像在桌面上摊那张图纸。

我们在学校读书的这几年，一直在听劳模精神。老师们课上讲，展馆里也讲。以前听“爱岗敬业、争创一流、艰苦奋斗、勇于创新”这一串词，却觉得像刻在墙上的字，看得见，摸不着。而那次从展馆出来之后，走回宿舍的那条路上，才把这串词跟具体的东西对上：是爱岗敬业，是明知这活又脏又累还愿意待在里面；是勇于创新，是图纸改到自己都烦了，是第二天还肯再摊开的东西。

写入党申请书的时候，“为人民服务”这几个字我写得特别顺，笔一落就出来。那几天翻来覆去地想，我到底为谁服务过？说出来不怕笑话，我能想起来的也就是搬桌子、带饭、替班里统计表格，但这些其实都不算什么。包起帆做的也不是什么惊天动地的事，就是一个抓斗一个抓斗地改，改到码头上的人不用再拿命去换那点工资。

所以我们具备劳模精神和创新精神根本就没想象的那么难。难的是你肯不肯迈出那一步，去切切实实的去做，去干，去实践，去创新。

这就是劳模成长之路——包起帆学长的创新之路带给我的启示。

## 二、逐段骨架

**第1段｜到场 + 预期落空**
- 时间：下午；人流：人不少，门口排了一小段队；具体标识：一进门，门厅墙上的一行字。
- 先立预期：一屋子奖状奖章，红底金字，一排排挂着。
- 再打掉：展柜里是器具、书信、小玩意——「平凡且真实」。
- 手法：不写背景，先给场景；「以为 A / 实际 B」制造落差。

**第2段｜外行疑问 + 反转**
- 动作：在器具跟前站了挺久。
- 说明：它们是抓斗，码头上抓木材、抓生铁用的。
- 念头：这东西有什么好创新的，不是很基本的东西吗？
- 反转：后来才知道，这些基本的东西就是包起帆学长的「创新之物」。
- 手法：外行视角的疑问，比直接赞美可信。

**第3段｜代际对照**
- 我们这代人的创新：立项、申报书、PPT、答辩、拿奖、简历上加一行。
- 他：焊缝和尺寸、真会砸到人、往前挪一寸算一寸、精益求精、日日夜夜、工匠技艺。
- 手法：先「我们」后「他」；对照项落到具体名词。

**第4段｜现场人物**
- 在场：庆幸包起帆本人在。
- 预期：劳模讲话会讲「工匠精神」之类的空话。
- 实际：讲哪一次没成、哪个零件试了多少回还是卡；语气像在说昨天的事；没有高大上的东西；都实实在在。
- 动作：手一直在动，比划着，像在桌面上摊那张图纸。
- 手法：用动作和语气代替「平易近人」这类评价。

**第5段｜学校里的词 + 走出来对上**
- 这几年一直听劳模精神；老师课上讲，展馆里也讲。
- 十六字像刻在墙上的字，看得见，摸不着。
- 回宿舍的路上，把词跟具体的东西对上：爱岗敬业=又脏又累还愿意待；勇于创新=改到自己都烦，第二天还摊开。
- 手法：「墙上的字」是枢纽比喻；把口号拆成动作。

**第6段｜自我审问 + 他的事**
- 入党申请书、「为人民服务」，写得顺。
- 自问：我到底为谁服务过？
- 答案：搬桌子、带饭、统计表格；「但这些其实都不算什么」。
- 他：做的「也不是什么惊天动地的事」；一个抓斗一个抓斗地改；拿命换那点工资。
- 手法：先把自己写小；反差落在「拿命换那点工资」。

**第7段｜结论：没那么难，难在肯不肯迈那一步**
- 判断：具备劳模精神和创新精神，根本就没想象的那么难。
- 转折：难的是你肯不肯迈出那一步。
- 动作链：去做，去干，去实践，去创新。
- 手法：结论落在动作上，不写「我们要努力」这种空话。

**第8段｜点题收尾**
- 「这就是劳模成长之路——包起帆学长的创新之路带给我的启示。」
- 手法：回到标题，不另起升华。

## 三、可迁移的写法

1. 开头三句内给具体：时间、人流、一个能看见的标识。
2. 先立预期再打掉：以为 A，实际 B；B 用清单，不用形容词。
3. 允许一个「不敬」的念头：这东西有什么好创新的？疑问比赞美可信。
4. 结论落到动作：「难的是你肯不肯迈出那一步，去……去做，去干，去实践」——别写「我们要努力」这种空话。
5. 对照要具体：不写「他更踏实」，写「他改的是焊缝和尺寸」。
6. 把口号拆成动作：爱岗敬业=又脏又累还愿意待；勇于创新=改到自己都烦还摊开。
7. 自我审问：我到底为谁服务过？先把自己写小，后面的道理才立得住。
8. 结尾点题：回到标题那句话，不另起升华。

## 四、语感标记

- 句长：长句后接短句；结论段两句，第二句连着四个「去……」。
- 连接：但 / 而 / 后来 / 结果 / 以前 / 那次 / 所以；不用「然而 / 因此 / 此外 / 综上所述」。
- 具体量词：一小段队、一屋子、一排排、一串词、一个抓斗一个抓斗。
- 口语词：挺久、实实在在、不怕笑话、高大尚、切切实实。
- 标点：问号 2；感叹号 0；破折号 3（标题、第1段、第8段各一）；冒号 4（「一行字：」「别的东西：」「另一副样子：」「对上：」）。
- 人称：第一人称「我」贯穿；「我们这代人」一次；结论段用「我们」总起。
- 段落：8 段；第7段是结论段，短，两句；第8段一句收。

## 五、给预设的用法

- 写 / 改学生心得、观后感、征文前，先读这份语料，对齐骨架和语感；事实必须来自用户原稿，不许搬样本里的人名、事件、数字。
- 用户贴稿并说「给 wpac 预设学习训练参考」：这是喂语料，不是改稿；原文一字不动，按原稿骨架沉淀（可做逐段对照说明）；动手前先确认是「喂语料」还是「改稿」。
- 改稿时只动说法，事实、结构、结尾不动；找不到用户说的旧架构，先停下来问。
- 改完先查冒号：总说 + 分说的地方，是不是被写成了逗号；冒号后面必须是清单或解释。
- 用户要「现场细节 / 见到本人」时：先问 1–2 个真实细节（看到什么、他说了什么、展馆里有什么）；没给就写概括，不许编签到本、小册子、明天的事。
- 数字 / 奖项最多 3–4 个，每个都要服务于一个判断；不要罗列。
