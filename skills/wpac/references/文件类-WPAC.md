# 文件类 WPAC（实验性）：PDF / PPT / Word / 表格

文字类的产物是聊天里的正文；文件类的产物是**一个文件**。规则不同，别混用。

## 0. 什么时候算文件类

- 用户要的是文件：`.pptx` / `.docx` / `.pdf` / `.xlsx` / `.csv`；
- 或者说法是「做一份 / 排一份 / 生成一份 / 整理成」+ 上面任一格式（讲稿、汇报、方案、讲义、台账）。
- 只是「写一份讲稿，内容给我」→ 仍是文字类。

## 1. 开头必须先问（S1.5）

一句话 + 两个选项（用 `ask_user_question`，别在聊天里问）：

> 这次要启用**文件类 WPAC（实验性）**吗？
> ① 启用：先问文件框架 → 弹结构确认 → 再生成文件（慢一点，结构可控）
> ② 不启用：按普通方式直接做（不问四轮、不弹窗）

用户没选之前：读资料、抓链接、看素材可以；**`write` / `office_*` / 生成文件的 bash 一律不许调**。
选②：当普通任务做，交付时注明「未启用文件类 WPAC」，不弹结构窗。

## 2. F1：只问两轮

**第一轮：给谁、解决什么**

- 这份文件给谁看（老师 / 领导 / 客户 / 自己复习）？
- 看完要做什么决定 / 拿到什么信息？
- 有没有参照件（旧版、模板、别人做过的）？

**第二轮：硬约束（多选）**

| 类目 | 选项举例 |
| --- | --- |
| 格式 | PPT / Word / PDF / Excel / CSV（默认按用户原话） |
| 体量 | 页数 / 时长 / 字数 / 行数（PPT 一页≈一分钟） |
| 模板 | 学校模板 / 公司模板 / 给我一套 / 不用 |
| 必须包含 | 目录 / 数据表 / 公式 / 图 / 参考文献 / 附录 |
| 禁止 | 不出现某类词 / 不放照片 / 不署名 / 不超过 N 页 |
| 素材 | 链接 / 文档 / 截图 / 没有（没有就按通用骨架） |

不要套文字类的四轮，也不要问「语气要口语还是正式」这种跟文件形态无关的槽。

## 3. F2：拆结构（弹窗里给用户看的 4–12 块）

`format` 与交付格式必须一致：PPT→`slides`、Word→`document`、PDF→`pdf`、表格→`table`。
每块：`title`（这页/节干什么）、`role`（封面/目录/论点/数据/收束…）、`summary`（一句话结论）、`text`（这页/节的要点或正文原稿，**不许写「此处展开」**）。

### PPT（slides）

| 块 | title 写法 | text 写什么 |
| --- | --- | --- |
| 封面 | 标题 + 副标题 | 题目、汇报人、日期 |
| 目录 | 三到五章 | 每章一句话 |
| 结论页（可选） | 一句话结论 | 结论 + 三条依据 |
| 正文页（3–6 页） | 一页一个论点（短句） | 标题层级 + 3–4 行要点 + 口播讲稿 |
| 数据页（可选） | 这张图说明什么 | 图/表 + 一句读法 |
| 结尾 | 收束 / 下一步 | 一句落点 + 待办 |

页数按用户时长定：20 分钟 ≈ 18–23 页（含封面目录结尾）。页数不够先补到数，别用一页塞三页的内容。

### Word / PDF 讲义（document / pdf）

| 块 | title 写法 |
| --- | --- |
| 封面 / 说明 | 这份文件解决什么 |
| 目录 | 章节目录 |
| 每章 | 章名（按课本/大纲的节号对齐） |
| 每节（可拆多块） | 这节要解决什么 → 定义 → 大白话 → 例题 → 易错 → 自测 |
| 附录 | 公式表 / 题型速查 / 答案 |

讲义类：节号必须跟课本一一对应；每节固定六段式，用户复习时能顺着看。

### Excel / CSV（table）

| 块 | text 写什么 |
| --- | --- |
| 明细表 | 列名 + 口径 + 3 行示例 + 校验规则 |
| 汇总表 | 分组维度 + 指标 + 公式说明 |
| 说明页/README | 每列含义、数据来源、更新日期 |

## 3.5 F2.5：页面预览（弹窗里显示的就是它）

结构确认弹窗选中某个模块时，右侧先显示**这一页的截图**，再下面是文字。所以 F3 之前要先把每块渲染成图：

| 交付物 | 怎么出图 | 取哪张 |
| --- | --- | --- |
| PPT | 先用 `office_write` / univer 出草稿 pptx → `office_render` 导出每页 PNG | 每块对应那一页 |
| Word / PDF | 出草稿 docx → `office_convert` 转 PDF → `office_render` 出每页 PNG | 这一节的起始页（一节跨多页时用首页，文字里说明跨几页） |
| Excel / CSV | `office_render` 指定 sheet + A1 范围出图 | 这一张表/这个区域 |
| 图片/资料页 | 直接复用已有 PNG | 对应页 |

- 图片放 `/tmp/wpac-preview/`（或工作区）下，文件名带序号，例如 `/tmp/wpac-preview/s03.png`；
- 把**路径**写进模块的 `preview` 字段；DSH 附件对象路径（`~/.dsh/attachments/...`，没有扩展名）也认，宿主按文件头嗅探 PNG/JPEG/WebP/GIF；`text` 仍然要写（图看不清时看文字）；
- 文件类**每块都必须有 `preview`**；实在出不了图就传 `previewUnavailable: true` 并在 `text` 写明原因，否则工具返回 `missing-preview` 打回；
- 出不了图（比如模型没有渲染工具）就留空，弹窗回退到文字，并在交付说明里写一句「本页无预览图」。
- 预览图只给结构确认用，不进正式交付物。

## 4. F3：结构确认

调 `wpac_structure_review`：

```json
{ "title": "微积分（上册）复习讲义", "kind": "PDF 讲义", "format": "pdf",
  "modules": [ { "id": "m1", "title": "第一章 函数与极限", "role": "主体", "summary": "把极限定义翻成大白话", "text": "本章 11 节……", "preview": "/tmp/wpac-preview/s01.png" } ] }
```

确认一轮就够：用户写意见 → 按 moduleId 改对应块 → 直接生成文件，**不再弹第二轮**。
`superseded` / `no-client` / `timeout` 一律不生成、不交付。

## 5. F4：文件自检（交付前必跑）

- 能正常打开（`office_read` 能读、`office_render` 能出图）；
- 页数 / 节数 / 表数跟确认过的结构一致，目录对得上页码；
- 没有占位文字：「此处展开」「TODO」「xxx」「待补充」；
- 中文标点、公式、代码块渲染正常；PPT 文字不出框、不压图；
- 字体嵌入（PDF 转换后不乱码）；表格列宽不撑破页面；
- 文件名带内容主题，不叫 `未命名 1`。

## 6. F5：交付

只给：文件路径 + 一行（格式 / 页数或字数 / 生成时间）。不贴文件全文，不附「如需修改请告诉我」。

## 7. 常见坑

1. **先建文件再问**——文件类最大的违规。用户没同意启用、F1 没问完，不许落盘。
2. **format 写错**——PDF 写成 document，弹窗会按「节」显示；要按页就写 `pdf`。
3. **text 写摘要**——弹窗右侧要看原文/要点，摘要会被用户当场发现。
4. **页数不达标**——PPT 用一页塞三页观点；讲义漏节。
5. **PDF 字体没嵌**——中文变方框；先转 docx 再导 PDF，导出后 render 一次确认。
6. **Excel 公式写死值**——汇总要能重算，别把结果当常数贴进去。
