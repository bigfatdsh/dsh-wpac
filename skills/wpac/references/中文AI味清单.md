# 中文 AI 味清单（写前读，写完逐条查）

> 参考：Wikipedia:Signs of AI writing；humanizer 的 zh-cues（中文 AI 味线索）；Unslop。
> 用法：心得、观后感、作文、口播、公众号，写完逐条过；命中 3 条以上就重写那一段。

## 一、十三个高频句式（命中就改）

1. **翻案句「不是 X，是 Y」/「是 X，不是 Y」**
   - 例：爱岗敬业不是不跳槽，是在一个行当里待得够久；本事是熬出来的，不是想出来的。
   - 改：只留肯定句——「爱岗敬业，就是在一个行当里待得够久」；**全篇 0 处**（含「算不上…只是」「与其说…不如说」）。
2. **金句结尾（每段一个 punchline）**
   - 例：有，就是服务；没有，就只是忙。／这话不好听，可比报告会上的话管用。
   - 改：停在事实、动作、原话上；全篇金句 ≤2。
3. **自我注解「所谓 X，说穿了……」/「这意味着」**
   - 例：所谓成长之路，说穿了不玄：盯住一个真问题……
   - 改：删掉这句，让事实自己说。
4. **聪明换算（把年份/数字做成对比）**
   - 例：1968 年……六年。这个数我算了半天，从大一到大四也就四年，再加两年研究生，正好凑齐。
   - 改：直接写「1968 年进码头，扛了六年木头」，不做换算。
5. **认知弧「我原先以为……后来才明白」**
   - 例：我原先以为是夸手巧，看了展板上的说明才明白……
   - 改：全篇最多 1 次；其余直接陈述。
6. **三连排比 / 四字格堆叠**
   - 例：排值班表、收材料、借教室、在群里催人填问卷。
   - 改：留两项，或拆成两句。
7. **机械让步段「听着像……可……」「这话不好听，可……」**
   - 改：让步要有着落，挂到具体事实上；不要每段都来一次。
8. **设问自答开头 / 显性路标**（首先、其次、最后、值得注意的是、总而言之）
   - 改：直接进场景；删路标。
9. **象征膨胀动词**（见证了、承载着、彰显了、是……的缩影）
   - 改：换成动作——「他改了三十多年抓斗」。
10. **机构腔 / 黑话**（赋能、抓手、闭环、打造、助力、擦亮名片）
    - 改：说人话——「给代理商做两场培训」。
11. **「就」字链**（就 / 就得 / 都得 / 一……就……）
    - 改：每段数一数「就」，超过 2 个就拆句。
12. **压缩句**（把人的苦难压成一句聪明话：不算新闻、不算什么、不过如此）
    - 改：把话写实——「砸下来的人，那几年不是一两起」。
13. **首尾升华**（宏大开场、拔高结尾）
    - 改：开头给具体场景；结尾停在动作或一句平话。

## 一·补、不像人话的构造（读出声就想删）

- 「离…很远，离…也远，但有些事离得不远」——排比式绕弯；改成直说「码头的事我没见过」。
- 「算个意外」——不像口语；改成「没想到能见着人」。
- 「…的账」当比喻（换绳的账）——改成具体的事「钢丝绳原来一个月换三四根」。
- 「验收人」「颗粒度」「底层逻辑」「闭环」「抓手」「范式」「复用」「对齐」——行业黑话，学生不会说。
- 「问不接」「这种事我不接」「接不住」「接得住」——硬造的接活隐喻，没人这么说；改成「干不了 / 做不来」，或者不写这种表态。

## 二、密度上限（心得 / 观后感，800–1000 字）

- 金句 / 格言 ≤2；对仗 0；翻案句 0；「我们」≤2；三连排比 0。
- 每段结尾不许都是判断；至少 2 段以事实 / 动作 / 原话收。
- 连续 2 段以上以判断收尾 = 违规；每 3 段至少 1 段以事实 / 动作 / 原话收。
- 标题用平实判断，不用「把 A 换成 B」式金句。
- 叙事 ≥50%，议论 ≤30%，过渡 ≤20%；议论段不超过 3 行。
- 「就」每段 ≤2。

## 三、现场细节：用户说概括就不编

- 用户说「没什么特别的 / 写概括就行」→ 不编具体场景、动作、心理（路过几回、算了半天、走出来发虚）。
- 用概括句：「我们这代人」「我身边」「多数时候」。
- 用户给了细节 → 用他的原话和动作，不改写、不添油。
- 展品、年份、年龄、奖项数：只写用户给的或查证过的；查不到就写「展柜里有旧物」，不写「一张 1978 年的成绩单」。
- 真人引语（「他说……」）和自己的事（抄作业 / 挂科 / 拖延）：没有原话或用户自述，一律不写。

## 四、硬要求清单（四轮后先写，交付前逐条打勾）

- 字数 / 篇幅（按用户口径：汉字数还是含标点字符数，交付前数一遍；先写到区间中上，改稿只会减字）
- 禁项（口号、小标题、编号、某些词）
- 选题 / 题目
- 细节来源（用户给 / 公开资料 / 只写概括）
- 截止 / 渠道

漏一条 = 没做完，重写那一条。

## 六、整段改法（真机成稿 → 平实版）
