# WPAC 管线（唯一主流程）

每篇文字成品都按这 8 段走；每段有入口条件和出口闸，跳段 = 不合格。

| 段 | 做什么 | 入口 | 出口闸 |
|---|---|---|---|
| 1 加载 | `skill(wpac)` | 接到文字成品委托 | 技能内容已读 |
| 2 问 | W → P → A → C1 → C2 → C3（→ C4…C6） | 加载完 | 四槽 + C 全部有答案；C3 起带「继续补充」 |
| 3 角色卡 | 我是谁 / 关心 / 不懂 / 怎么讲 / 不能写 | W 有答案 | 五项写完；至少一半段落能从「我」出发 |
| 4 路由 | 心得→学生心得；小说→自由之人；公文→不读；改稿→对照 | 文体判断 | 只读对口 1 份 |
| 5 写 | 事实只用手上有的；细节只用概括；先口述再落字 | 角色卡 + 语料 | 初稿完；无编造 |
| 6 改三遍 | 删范文腔 → 拆对仗/旁观摘要 → 出声读 | 初稿 | 黑名单命中 = 0 |
| 7 闸 | `preflight --no-details`；硬要求清单逐条打勾 | 改完 | preflight 全绿 + 清单全勾 |
| 8 交付 | 只输出正文 | 闸过 | 无说明 / 字数 / 客套 |

## 每段细节

1. **加载**：不加载 = 没读语料；见技能 §0 / §12。
2. **问**：一轮一题；C 分 C1 形式 / C2 内容 / C3 提交；C3 起「继续补充」，C4→C5→C6，C6 收口。
3. **角色卡**：见 `references/W角色卡.md`；旁观摘要（谁见谁、听没听清、走一圈）不写。
4. **路由**：见技能 §0；只读对口 1 份，最多 2 份。
5. **写**：用户没给的细节不编；数字 / 奖项 ≤3–4；真人引语要出处；废话只许抽象，不许展开成画面（大红花 / 证书 / 台上笑）；口述法：先当微信语音讲 60 秒，再落字。
6. **改**：见 `references/反例-作文腔.md`；对仗拆成先后的事；删三句最像范文的，删完通顺就保持删除。
7. **闸**：`preflight --no-details` 红了改到绿；硬要求清单（字数 / 禁项 / 选题 / 细节来源 / 截止）逐条打勾。
8. **交付**：纯正文；不加说明、字数、客套。

## 故障对照

- 不加载技能 → 语料没喂，风格照旧。
- 不问 C1/C2/C3 → 硬要求漏。
- 没角色卡 → 旁观摘要、专家口吻。
- 语料不对路 → 小说腔 / 作文腔。
- 编细节 → preflight 事实闸 FAIL。
- 没跑 preflight → 作文腔漏出。
